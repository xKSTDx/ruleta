# Ruleta de sorteo

Ruleta para sorteos del fort.

- Pega o importa una lista (.txt) con el formato `Nombre 99`, una línea por usuario.
- La lista y el historial se guardan en tu navegador (localStorage).
- Exporta el historial como `ganadores_dia-mes-año.txt`.
- Comparte la lista por enlace, con o sin los ganadores anteriores.
- Sonidos opcionales: `sonidos/win.mp3` y `sonidos/lose.mp3`.
